How I designed the workflow

  1. Define the inputs

    Start with the survey responses and scoring rules. Add customer profiles when they’re available.

  2. Specify the output

    Show the overall score and how many responses it uses. Keep findings tied to the source evidence.

  3. Test what breaks

    Try missing profile data and repeated responses. Check the result against a score you can calculate by hand.

How I’d teach it

I’d ask learners to bring a task they repeat at work and write down one result they can verify themselves. Then we’d introduce a missing input or a duplicate, compare what the assistant did with what they expected, and revise the instructions together.
