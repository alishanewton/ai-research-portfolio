# AI research portfolio

A responsive, self-contained portfolio case study for Alisha Newton-Rudhru. Open index.html in a browser. No installation or build step is required.

## GitHub Pages

In the repository, open Settings → Pages. Choose Deploy from a branch, main, and / (root), then Save.

## Demo

The missing-profile example reports 60% (6/10). The duplicate-response example keeps the latest response and reports 70% (7/10). All survey rows are fictional. No data leaves the browser.

Search indexing is discouraged with the original noindex, nofollow meta tag.
